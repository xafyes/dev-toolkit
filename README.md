# dev-toolkit

Skills personales de Claude Code para desarrollo, instaladas en cada sesión nueva (vía setup script del entorno) sin importar el repo del proyecto.

- `CLAUDE.md` — reglas globales de comunicación, código y seguridad.
- `skills/` — una skill por carpeta (`SKILL.md`): `memory-vault`, `project-kickoff`, `viability-review`, `ux-ui-review`, `qa-bughunt`, `stack-watch`, `dev-agents`.

El detalle de estándares (código, seguridad, infra, viabilidad) vive en el repo `dev-vault`, no aquí.
